# Amazon India Sales Analysis Dashboard

## Project Overview
This project analyzes Amazon India sales data using Microsoft Power BI. It presents sales performance, profit trends, order status, product performance, and category-wise insights through interactive dashboards.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Pages

### 1. Executive Sales Overview
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales Trend
- Category-wise Sales and Profit
- Order Status Distribution

### 2. Product Analysis
- Top 10 Products by Sales
- Monthly Profit Trend
- Category-wise Units Sold
- Returns and Cancellations Analysis

## Project Files
- `Amazon_India_Sales_Dashboard.pbix` – Power BI dashboard
- Dataset Excel file – Source sales data

## Objective
To analyze sales data and identify business insights that can support better decision-making.
